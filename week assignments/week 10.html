ProtoSem Journal – Week 10

Smart Factory Automation and LabVIEW

This week focused on understanding the fundamentals of Smart Factory Automation and exploring the working principles of LabVIEW (Laboratory Virtual Instrument Engineering Workbench). The session introduced how software-based monitoring, data acquisition, and control systems contribute to industrial automation. I explored how graphical programming can be used to develop automation logic and connect software interfaces with real-world engineering applications.

What I learned

  • Understood the basic concepts of smart factory automation and its role in modern manufacturing.
  • Learned about LabVIEW and its graphical programming environment.
  • Explored how block diagrams and graphical code are used to represent program logic.
  • Gained an understanding of data acquisition, signal monitoring, and control system concepts.
  • Learned how software tools can support industrial process monitoring and automation.
  • Recognized the importance of integrating sensors, controllers, and software to improve manufacturing efficiency.

Big takeaway

Smart factory automation combines industrial hardware, software, and real-time data to improve productivity, monitoring, and process control. LabVIEW provides a graphical programming approach that helps engineers develop and visualize measurement and automation applications.

Learning reflection

Smart factory automation

During this session, I explored the role of automation in modern manufacturing environments. Smart factories use connected devices, sensors, control systems, and software to monitor operations and improve process efficiency. This helped me understand how automation supports consistent production and better decision-making.

LabVIEW software

I was introduced to LabVIEW, a graphical programming platform used for measurement, instrumentation, data acquisition, and control applications. I learned about its front panel, which provides the user interface, and its block diagram, which defines the program logic. This introduced me to an alternative approach to programming engineering systems.

Industrial automation and software integration

The session helped me understand how graphical programming tools can support the development of monitoring and control applications. Integrating software with sensors and industrial equipment enables engineers to observe system behaviour, process data, and implement automation logic.

Final reflection: Week 10 helped me connect software programming with industrial automation. Learning about smart factories and LabVIEW broadened my understanding of how engineering software supports monitoring, measurement, and control in modern manufacturing systems. This experience strengthened my interest in automation technologies and the integration of software with industrial processes.
