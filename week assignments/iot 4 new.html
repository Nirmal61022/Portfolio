TASK 4 — FIREBASE IoT MONITORING DASHBOARD

1. Introduction

The Firebase IoT Monitoring Dashboard is an IoT-based system developed using an ESP32, DHT11 temperature and humidity sensor, LDR sensor, relay module, and Firebase.

The system collects environmental data using sensors and sends the data to Firebase Realtime Database through Wi-Fi. A web-based dashboard allows the user to monitor the sensor values remotely. The dashboard also provides control of a bulb through a relay.

The project demonstrates the integration of IoT, embedded systems, cloud computing, databases, authentication, and web technologies.

2. Objective

The main objectives of this project are:

  • To monitor temperature and humidity using a DHT11 sensor.
  • To monitor ambient light using an LDR.
  • To send sensor data to Firebase through an ESP32.
  • To display sensor values on a cloud-based dashboard.
  • To control a bulb remotely using a relay.
  • To implement user login using Firebase Authentication.
  • To understand the application of cloud computing in IoT.
  • To establish two-way communication between the ESP32 and web dashboard.

3. Basic Concept of Cloud Computing

Cloud computing is the delivery of computing services such as storage, databases, servers, and software through the Internet.

Instead of storing all data locally, a cloud service allows data to be stored on remote servers and accessed from different devices.

Advantages

  • Remote access
  • Real-time data synchronization
  • Scalable storage
  • Easy IoT integration
  • Reduced local infrastructure
  • Centralized data management

In this project, Firebase is used as the cloud platform.

Data Flow

ESP32 → Wi-Fi → Firebase → Dashboard

Control Flow

Dashboard → Firebase → ESP32 → Relay → Bulb

12. LDR Sensor

An LDR, or Light Dependent Resistor, changes its resistance according to the intensity of light falling on it.

In this project, the LDR is used to monitor ambient light.

The LDR is connected to an analog input of the ESP32. The ESP32 reads the analog value and sends it to Firebase.

Data Flow

18. ESP32 Source Code

The ESP32 program performs the following functions:

  • Connects to Wi-Fi.
  • Connects to Firebase.
  • Reads DHT11 temperature.
  • Reads DHT11 humidity.
  • Reads LDR value.
  • Uploads sensor values to Firebase.
  • Reads bulb-control status.
  • Controls the relay.

Complete ESP32 Code

#include <WiFi.h>

#include <Firebase_ESP_Client.h>

#include <DHT.h>

#define WIFI_SSID "YOUR_WIFI_NAME"

#define WIFI_PASSWORD "YOUR_WIFI_PASSWORD"

#define API_KEY "YOUR_FIREBASE_API_KEY"

#define DATABASE_URL "YOUR_FIREBASE_DATABASE_URL"

#define USER_EMAIL "YOUR_FIREBASE_EMAIL"

#define USER_PASSWORD "YOUR_FIREBASE_PASSWORD"

#define DHT_PIN 4

#define DHT_TYPE DHT11

#define LDR_PIN 34

#define RELAY_PIN 5

DHT dht(DHT_PIN, DHT_TYPE);

FirebaseData fbdo;

FirebaseAuth auth;

FirebaseConfig config;

unsigned long previousMillis = 0;

const unsigned long interval = 2000;

void setup()

{

  Serial.begin(115200);

  pinMode(LDR_PIN, INPUT);

  pinMode(RELAY_PIN, OUTPUT);

  digitalWrite(RELAY_PIN, LOW);

  dht.begin();

  WiFi.begin(WIFI_SSID, WIFI_PASSWORD);

  Serial.print("Connecting to Wi-Fi");

  while (WiFi.status() != WL_CONNECTED)

  {

    Serial.print(".");

    delay(500);

  }

  Serial.println();

  Serial.println("Wi-Fi connected");

  Serial.print("IP Address: ");

  Serial.println(WiFi.localIP());

  config.api_key = API_KEY;

  config.database_url = DATABASE_URL;

  auth.user.email = USER_EMAIL;

  auth.user.password = USER_PASSWORD;

  Firebase.begin(&config, &auth);

  Firebase.reconnectWiFi(true);

  Serial.println("Connecting to Firebase...");

  while (!Firebase.ready())

  {

    Serial.print(".");

    delay(500);

  }

  Serial.println();

  Serial.println("Firebase connected");

}

void loop()

{

  if (millis() - previousMillis >= interval)

  {

    previousMillis = millis();

    float temperature = dht.readTemperature();

    float humidity = dht.readHumidity();

    int ldrValue = analogRead(LDR_PIN);

    if (isnan(temperature) || isnan(humidity))

    {

      Serial.println("DHT11 reading failed");

      return;

    }

    Serial.println("-------------------------");

    Serial.print("Temperature: ");

    Serial.print(temperature);

    Serial.println(" °C");

    Serial.print("Humidity: ");

    Serial.print(humidity);

    Serial.println(" %");

    Serial.print("LDR: ");

    Serial.println(ldrValue);

    if (Firebase.ready())

    {

      Firebase.RTDB.setFloat(&fbdo, "/IoT/sensors/temperature", temperature);

      Firebase.RTDB.setFloat(&fbdo, "/IoT/sensors/humidity", humidity);

      Firebase.RTDB.setInt(&fbdo, "/IoT/sensors/ldr", ldrValue);

      if (Firebase.RTDB.getBool(&fbdo, "/IoT/control/bulb"))

      {

        bool bulbState = fbdo.boolData();

        if (bulbState == true)

        {

          digitalWrite(RELAY_PIN, HIGH);

          Serial.println("Bulb: ON");

        }

        else

        {

          digitalWrite(RELAY_PIN, LOW);

          Serial.println("Bulb: OFF");

        }

      }

      else

      {

        Serial.print("Firebase control read failed: ");

        Serial.println(fbdo.errorReason());

      }

    }

  }

}

22. Reflection

This assignment provided practical experience in integrating IoT hardware with cloud computing and web technologies.

I learned how the ESP32 collects data from physical sensors and sends it to Firebase through Wi-Fi. I also learned how Firebase Realtime Database can synchronize information between an embedded device and a web dashboard.

The project improved my understanding of authentication, databases, cloud platforms, real-time communication, and remote appliance control.

The most important concept learned from the project was the complete IoT communication flow:

Sensor → ESP32 → Internet → Firebase → Dashboard

and the reverse control flow:

Dashboard → Firebase → ESP32 → Relay → Bulb

The project also improved my debugging skills by requiring troubleshooting of hardware connections, sensor libraries, Wi-Fi connectivity, Firebase configuration, database paths, authentication, and dashboard code.

23. Conclusion

The Firebase IoT Monitoring Dashboard successfully demonstrates a cloud-connected IoT system using ESP32, DHT11, LDR, Firebase, and a relay-controlled bulb.

The system provides remote monitoring of temperature, humidity, and light conditions and allows the user to control a physical bulb through a web dashboard.

The project demonstrates the practical use of:

  • IoT
  • ESP32
  • Sensors
  • Cloud computing
  • Firebase Realtime Database
  • Authentication
  • Web dashboards
  • Remote appliance control

The final system provides two-way communication between the physical device and cloud dashboard, demonstrating how IoT devices can be monitored and controlled remotely.
