Task 03

Google Voice Assistant Controlled Bulb

Google Assistant · IFTTT · Webhooks · Adafruit IO · MQTT · ESP32 · Relay

1. Project Overview

I developed a voice-controlled IoT system to control a 230 V AC bulb using an ESP32, relay module, Adafruit IO, IFTTT, and Google Assistant.

The project extends the previous cloud-based relay control system by adding a voice-control layer. Instead of manually pressing an ON/OFF button on the Adafruit IO dashboard, I used voice commands through Google Assistant.

When a voice command is given, Google Assistant triggers an IFTTT automation. IFTTT sends the corresponding command through a webhook to the cloud platform. Adafruit IO then publishes the command through MQTT, which is received by the ESP32.

The ESP32 processes the command and controls the relay connected to the 230 V AC bulb.

2. Objective

The main objective of this project was to control a 230 V AC bulb using voice commands.

Objectives

  • Control an IoT device using voice commands.
  • Integrate Google Assistant with an IoT system.
  • Understand IFTTT automation.
  • Understand webhook-based communication.
  • Connect IFTTT with Adafruit IO.
  • Use MQTT for communication with the ESP32.
  • Control a relay through ESP32.
  • Turn the connected bulb ON and OFF using voice commands.
