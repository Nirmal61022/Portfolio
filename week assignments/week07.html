IoT, Connectivity & RTOS

This week focused on understanding IoT, wireless connectivity, cloud communication, and Real-Time Operating Systems (RTOS) using the ESP32 development platform. We worked with the Arduino IDE to build connected applications and explored different methods of controlling hardware through web interfaces, MQTT communication, voice commands, and Firebase. We also learned the fundamentals of RTOS and applied task-based programming concepts in a practical project.

What I learned

  • Learned how to program the ESP32 using Arduino IDE for IoT applications.
  • Understood how a microcontroller can communicate with devices through Wi-Fi and web interfaces.
  • Developed a web-based LED control system using the ESP32.
  • Learned the fundamentals of MQTT communication and connected the ESP32 to a cloud platform.
  • Explored voice-based control for interacting with connected hardware.
  • Learned how Firebase can be used for real-time data communication and smart-home applications.
  • Understood the basic concepts of Real-Time Operating Systems (RTOS), including tasks, scheduling, delays, and task management.
  • Applied RTOS concepts by creating a small multi-tasking ESP32 project.

Big takeaway

IoT systems are not limited to controlling hardware locally; they enable devices to communicate with web applications, cloud platforms, and other connected systems. This week helped me understand how ESP32, wireless communication, cloud services, and RTOS can work together to build responsive and connected embedded applications.

Learning reflection

ESP32 and web-based control

During the first activity, I learned how the ESP32 can be connected to a Wi-Fi network and controlled through a web interface. I understood how a microcontroller can act as a web server and receive commands from a browser. This helped me connect embedded programming with basic web technologies and understand the concept of remote hardware control.

MQTT cloud communication

I also explored MQTT, a lightweight communication protocol commonly used in IoT systems. I learned how devices can publish data to topics and subscribe to topics to receive commands. Working with MQTT helped me understand how an ESP32 can communicate with cloud-based IoT platforms and other connected devices.

Voice-based control

The voice-control activity introduced me to another method of interacting with IoT systems. Instead of relying only on physical switches or web interfaces, voice commands can be used to control connected devices. This helped me understand how different user interfaces can be integrated with embedded systems.

Firebase smart home system

Using Firebase, I learned how cloud-based services can be used to exchange data between an IoT device and an application. The smart-home activity demonstrated how device states can be monitored and controlled remotely. This gave me a better understanding of real-time cloud connectivity and how IoT systems can be extended beyond the local network.

Real-Time Operating System

The final part of the week focused on RTOS concepts. I learned that an RTOS allows an embedded system to divide its operation into independent tasks that can be scheduled and executed efficiently. Concepts such as tasks, task delays, scheduling, task priorities, and multitasking helped me understand how more complex embedded applications can be structured.

I applied these concepts on the ESP32 by developing a small project with multiple tasks. This showed me how different operations such as LED control, button input, sensor monitoring, and communication can be handled independently rather than being written as one continuous program.

Final reflection: Week 7 gave me a practical understanding of how embedded systems become connected and intelligent through IoT communication, cloud platforms, wireless connectivity, and RTOS-based multitasking. The activities helped me move beyond basic microcontroller programming and understand how real-world connected systems are designed, controlled, and managed.
