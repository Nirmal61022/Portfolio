ESP32 230 V AC Bulb Control Using Adafruit IO

ESP32 · Wi-Fi · MQTT · Adafruit IO · Relay · 230 V AC Load

1. Project Overview

I developed an IoT-based 230 V AC bulb control system using an ESP32, relay module, and Adafruit IO cloud dashboard.

The ESP32 connects to the internet through Wi-Fi and communicates with the Adafruit IO platform using MQTT. An ON/OFF control on the Adafruit IO dashboard sends a command to the ESP32. The ESP32 processes the received command and controls a relay module.

The relay electrically switches the connected 230 V AC bulb, allowing the bulb to be controlled remotely through the Adafruit IO web dashboard.

This project helped me understand MQTT communication, cloud-based IoT control, relay interfacing, and remote electrical-load control.

2. Objective

The main objective of this project was to control a 230 V AC bulb remotely using an ESP32 and an Adafruit IO web dashboard.

Objectives

  • Connect ESP32 to a Wi-Fi network.
  • Connect ESP32 to Adafruit IO.
  • Understand MQTT publish-subscribe communication.
  • Create an ON/OFF control on the Adafruit IO dashboard.
  • Receive commands on the ESP32.
  • Interface an ESP32 with a relay module.
  • Control a 230 V AC bulb using the relay.
  • Demonstrate remote IoT-based electrical load control.

Important Point

The ESP32 does not directly switch the 230 V AC bulb.

The ESP32 provides the low-voltage control signal to the relay module, while the relay provides electrical isolation between the control side and the AC load side.

6. Working Principle

The system works through a cloud-based MQTT communication path.

When the user selects ON or OFF on the Adafruit IO dashboard, the corresponding value is published to an MQTT feed.

The ESP32 is subscribed to this feed.

When the ESP32 receives the command:

ON  → Relay activated → Bulb ON

OFF → Relay deactivated → Bulb OFF
