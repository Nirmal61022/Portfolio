ESP32 Built-in LED Web Control

ESP32 · Wi-Fi · Web Server · GPIO · HTML/CSS/JavaScript

1. Project Overview

I developed a simple IoT-based LED control system using an ESP32 development board. The built-in LED of the ESP32 was controlled through a web interface.

The ESP32 was connected to a Wi-Fi network and configured as a local web server. A web page was used to send ON and OFF commands to the ESP32. The ESP32 received the commands through HTTP requests and controlled its built-in LED accordingly.

This project helped me understand the basic relationship between an embedded controller, Wi-Fi communication, HTTP requests, and a web-based control interface.

2. Objective

The main objective of this project was to control the ESP32's built-in LED wirelessly using a web browser.

Objectives

  • Connect ESP32 to a Wi-Fi network.
  • Configure ESP32 as a local web server.
  • Control the built-in LED through GPIO.
  • Create a web interface for LED control.
  • Send ON and OFF commands from the browser.
  • Understand basic HTTP communication.
  • Observe the physical LED responding to web commands.

6. Step-by-Step Implementation

Step 1 — Install Arduino IDE

First, I installed the Arduino IDE on the computer.

The Arduino IDE was used to write, compile, and upload the ESP32 program.

Step 2 — Add ESP32 Board Support

I added the ESP32 board package to Arduino IDE through the Board Manager.

After installation, the ESP32 development board became available under:

Tools → Board

Step 3 — Connect ESP32

I connected the ESP32 development board to the computer using a USB cable.

The USB connection was used for:

  • Programming
  • Serial communication
  • Powering the ESP32 during testing

Step 4 — Select ESP32 Board

I selected the appropriate ESP32 board from:

Tools → Board → ESP32

I then selected the corresponding COM port under:

Tools → Port

Step 5 — Configure Wi-Fi

The Wi-Fi network name and password were entered into the ESP32 program.

const char* ssid = "YOUR_WIFI_NAME";

const char* password = "YOUR_WIFI_PASSWORD";

The ESP32 uses these credentials to connect to the local Wi-Fi network.

Step 6 — Configure the Built-in LED

The built-in LED was assigned to the ESP32 GPIO used by the development board.

const int ledPin = 2;

The GPIO was configured as an output:

pinMode(ledPin, OUTPUT);

No external wiring was required.

Step 7 — Create the Web Server

A web server was created on the ESP32.

WebServer server(80);

Port 80 was used for HTTP communication.

The ESP32 therefore acts as both:

  • Wi-Fi client
  • Local HTTP server

Step 8 — Create ON and OFF Commands

Two HTTP endpoints were created for controlling the LED.

/api/on

/api/off

The ON command changes the GPIO state to HIGH:

digitalWrite(ledPin, HIGH);

The OFF command changes the GPIO state to LOW:

digitalWrite(ledPin, LOW);



7. Upload the Program

After completing the program, I compiled it using Arduino IDE.

I then uploaded the program to the ESP32 through the USB connection.

After successful uploading, the ESP32 started executing the program.

8. Connect ESP32 to Wi-Fi

After restarting, the ESP32 attempted to connect to the configured Wi-Fi network.

The connection status was monitored using the Serial Monitor.

The Serial Monitor was opened at:

115200 baud

Once connected, the ESP32 displayed its assigned local IP address.

Example:

WiFi Connected

IP Address: 192.168.x.xxx



9. Open the Web Interface

I entered the ESP32's IP address into a browser connected to the same Wi-Fi network.

Example:

http://192.168.x.xxx

The browser then communicated directly with the ESP32 through the local network.
